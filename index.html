THE BASICS 🌱

What exactly is LIME?

LIME stands for Local Interpretable Model-agnostic Explanations. It explains an individual prediction by approximating a complex model locally with a simpler, interpretable model.

🔎

Local explanations

LIME focuses on one prediction at a time rather than explaining the whole model at once.

🧩

Simple interpretation

It uses a simpler local model to show which input features influenced the selected prediction.

💚

Model-agnostic

LIME can explain predictions from different types of models when a suitable prediction interface is available.

🌿 The key idea

LIME creates perturbed samples around an example, observes the original model's predictions, and fits a locally weighted interpretable model. The explanation approximates the model near that particular example; it may not describe the model everywhere.
