The idea behind LIME

How does the experiment work?

① 🧍

Select one case

Start with a single prediction from a model. LIME focuses on understanding this individual result.

② 🫧

Explore nearby cases

Create small variations of the selected example and observe how the simulated model responds.

③ 💡

Explain locally

Use a simpler, interpretable approximation to show which features matter around the selected case.

Two different approaches

LIME and SHAP are not the same 🌱

🌿 LIME

Local approximation: investigates one prediction by creating nearby examples and fitting a simpler explanation around that case.

Focus: one case

✨ SHAP

Feature attribution: assigns contribution values to features using Shapley-value ideas. It can explain individual predictions and summarize patterns across many cases.

Focus: feature contributions
